# OfflineWorldGPS – Téléchargements

Ce dépôt public héberge les packs d’adresses hors ligne utilisés par l’application Android OfflineWorldGPS.

Pays prévus :

- Suisse
- France
- Espagne

Les packs pourront être téléchargés directement depuis l’application, par Wi‑Fi ou données mobiles, y compris en itinérance selon les réglages du téléphone.

Les données cartographiques et d’adresses proviennent d’OpenStreetMap et de ses contributeurs, sous licence ODbL.
